# Competitive Analysis Workflow

## Steps

1. **Read the Product Manager skill** — Load `.agents/skills/product-manager/SKILL.md` and follow the Competitive Analysis Framework.

2. **Identify competitors** — Research direct competitors (same category), indirect competitors (different solution to same problem), and substitutes (e.g., spreadsheets).

3. **Build feature parity matrix** — Compare features across competitors using a structured table.

4. **Assess moats** — For each competitor, evaluate: network effects, switching costs, data advantages, brand trust, cost structure.

5. **Find counter-positions** — Identify strategic positions competitors cannot copy without hurting themselves.

6. **Deliver** — Create an artifact with:
   - Feature parity matrix
   - Strategic group map (positioning diagram)
   - Moat assessment
   - Counter-positioning opportunities
   - Recommended strategic response
